### consolation-of-philosophy-alfred-prose / -lays — heading + line-break reformat
Both texts (collection `consolation-of-philosophy-alfred`) were staged 2026-07-13, before the
pipeline ran `normalise-markdown.mjs` automatically. In the DB their section markers sat as bare text
lines (so they merged into the following paragraph) and — in the verse text — every line was joined
into one run-on block, because Markdown collapses a single newline to a space.

**Fix (`scripts/ingestion/reformat-boethius-bodies.mjs`, deterministic + idempotent):**
- **Prose:** promoted `Proem`, `Boethius and Theodoric`, the 42 roman-numeral section numbers
  (I–XLII) and the closing `FINIT.` to `##` headings (0 → 45); ran the shared `normaliseMarkdown`
  (`treatAllAsProse`, since this edition sets the meters as running prose) to insert real paragraph
  boundaries. The M./P./B. stichomythia now splits into separate numbered paragraphs.
- **Verse:** promoted `PRELUDE` and the 31 `N: Boethius. …` lay markers to `##` headings (0 → 32);
  dropped the redundant bare `LAYS` divider (the title already says "The Lays"); gave every line
  within a lay a CommonMark hard break (trailing `\`) so the poetry renders line-by-line. Verified
  through the reader's actual `react-markdown` + `remark-gfm` pipeline: the prelude renders as an
  `<h2>` plus one paragraph with a `<br>` between each verse line.

Output files under `scripts/ingestion/output/consolation-of-philosophy-alfred/` were rewritten in
place (frontmatter untouched). Before/after preview rendered through the site reader:
https://claude.ai/code/artifact/e74d5842-ef16-4bf9-baff-8646e2bcf37c

column only, and is idempotent (a body already matching is skipped). It changes nothing else — not
`published`, `note_draft`, `editorial_introduction`, themes, genre or author.
