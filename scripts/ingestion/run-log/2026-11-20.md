## What this run taught (for the weekly run)
- **CCEL plain text needs a committed path.** Four of the five top-scored prospects were CCEL
  `cache/*.txt` exports, and `fetch-texts.mjs` treats every source as HTML. This run used a one-off
  parser; the weekly run needs a committed one (rule-separated sections, flush or centred headings,
  `[n]` footnote apparatus dropped). It rides with the card's code PR.
- **A sync-time URL is a claim, not a source.** Two of eight candidates pointed at the wrong page
  (Westminster, Re-Baptism) and one staged file was a website's chrome (Jewel). Reading the title
  before fetching caught all three; a status-code check would have passed every one.
- **Meters touched:** Supabase egress (the importer's per-slug existence checks and this
  verification query, which selected metadata columns only, no bodies); no Vercel work; no log reads.
