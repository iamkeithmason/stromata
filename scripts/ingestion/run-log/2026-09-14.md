## Environment note — outbound network restricted this session

This session's egress policy allowed only `newadvent.org`, `gutenberg.org`, `ccel.org`, and `anglicanhistory.org`; `archive.org`, `wikisource.org`, `sacred-texts.com`, `anglicanheritage.com`, and `faculty.georgetown.edu` all returned `connect_rejected` (organization policy, not a transient failure — confirmed via the agent-proxy status endpoint). This shaped two decisions:

- **Notion sync** found several good "Text available" candidates (Small Catechism/Luther, Book of Pastoral Rule/Gregory — both, on checking, already fully imported under different queue ids; several Reformation-era prospects on `archive.org`) but most were unreachable this session or already covered. Only `the-shepherd-of-hermas` (New Advent, safe) cleared both the reachability and copyright bars cleanly, so only 1 of the permitted 5 was added rather than padding the queue with prospects this session couldn't act on anyway.
- **Stage 1–4 processing** was scoped to New-Advent-sourced prospects for the same reason, which is why this run reads as a coherent "Apostolic Fathers" batch rather than a scattershot pick — it's a constraint of this session's network policy, not an editorial theme.

**No `ANTHROPIC_API_KEY` is configured in this environment**, so `fetch-texts.mjs`'s inline `note_draft` generation was skipped for all 6 prospects (it degrades gracefully rather than failing). All 8 `note_draft`s were written by hand this run, following the museum-label register in `scripts/lib/note-prompt.mjs`'s `NOTE_PROMPT` (3–4 sentences, opens on a concrete textual detail, no templated closer).
