## Tooling: split-into-chapters `--kind` flag (code change, see CHANGELOG)
`split-into-chapters.mjs` auto-picked the most-frequent marker as the chapter boundary, which
mis-split nested works. Added `--kind=CHAPTER` to force the coarse level. Validated on Holy Dying
(5 chapters vs 36 sections).

## the-rule-and-exercises-of-holy-dying-taylor — Jeremy Taylor · Treatise · 5 chapters
First CCEL `.txt`-sourced collection, validating the whole chain:
1. Fetched the CCEL plain-text cache: `https://ccel.org/ccel/t/taylor/holy_dying/cache/holy_dying.txt`
   (627 KB; the reading page is a JS SPA, the `.txt` is the fetchable form). Author Jeremy Taylor
   (1613–1667), *Holy Dying* first published 1651 — original English composition, public domain.
2. `split-into-chapters.mjs --kind=CHAPTER` → 5 chapter files (CCEL header discarded as front matter,
   paragraphs reflowed).
3. **Body cleaning** (CCEL-specific, done as a scoped post-split pass): stripped the footnote
   apparatus — CCEL formats footnotes as `[N] text` lines interspersed in the body plus inline `[N]`
   markers, which the djvu-oriented footnote-deinterleave doesn't catch — and the `_____` CCEL
   dividers. Result: clean reading prose (footnotes dropped, per the reading-edition default).
4. Real chapter titles set (the five books of Holy Dying); per-chapter themes (death throughout;
   consideration→contemplation, exercise→prayer, sickness→suffering/spiritual-warfare,
   graces→virtue/salvation, visitation→ministry/sacraments).
5. **note_drafts generated** via the shared `generateNoteWithCritic` (critic loop) with **sibling
   de-clustering** (each note gets the previously-generated ones so the five don't converge) —
   scores 7–8. Done into the frontmatter *before* import, so the global `generate-note-drafts.mjs`
   backfill wasn't needed (it would have touched 4 unrelated null-note rows).
6. Imported and verified via collections→texts join: 5 texts, orders [1–5], published:false, EI NULL,
   note_draft present, 5 themes each, genre Treatise, author Jeremy Taylor non-draft, bodies 44k–145k.

Status: imported. The CCEL chain is now proven; the rest of the lane (Calvin, Hooker, Wesley, Julian,
Schaff, the Clement Exhortation) can follow the same shape.
